## 裸金属到底"裸"在哪：先把概念对齐

简单说，裸金属服务器（Bare Metal Server）就是一台没有任何虚拟化层的独立物理服务器。操作系统直接跑在硬件上，不像 VPS 那样被 Hypervisor 切成好几份分给不同租户。这意味着：

- **单租户、完全隔离**：没有"邻居"和你抢 CPU 时间片，也不存在超售（oversubscription）这种事；
